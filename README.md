One funny name for a band made of robots, with a few words on its hit song, under 200 characters.

The name turns a machine meltdown into a death-metal act, the kind of band name a person would actually repeat. The song title takes a human breakup line and hands it to the crashed machine: "driver" is at once the person behind the wheel and the piece of software that took the band down, so the second laugh comes from the excuse rather than from repeating the joke.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes the text to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt` with no clock, randomness, network, or secrets, so two runs produce byte-identical output.
